# Actividad-2

•	Qué hace el proyecto.
Este proyecto es una aplicación de automatización de llamadas que permite gestionar, programar y ejecutar llamadas de manera eficiente mediante el uso de tecnologías digitales. La herramienta puede integrarse con bases de datos de clientes, sistemas de atención y flujos automatizados para optimizar procesos de comunicación.

•	Por qué el proyecto es útil.
Este proyecto es útil porque:

Reduce el tiempo y esfuerzo en la gestión manual de llamadas.
Mejora la eficiencia en procesos de atención al cliente, ventas o seguimiento.
Permite escalar la comunicación con múltiples usuarios de forma organizada.
Puede ser aplicado en sectores como servicio al cliente, salud, educación y marketing.

•	Cómo pueden comenzar los usuarios con el proyecto.
Para comenzar a usar este proyecto:

Clonar el repositorio:
git clone https://github.com/tu-usuario/tu-repositorio.git
Instalar las dependencias:
pip install -r requirements.txt
Configurar las variables de entorno (API keys, servicios de llamadas, etc.).
Ejecutar la aplicación:
python main.py
Personalizar los flujos de llamadas según las necesidades del usuario.
